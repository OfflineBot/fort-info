📖 Glossar

40 Schlüsselbegriffe aus allen 7 Themen — alphabetisch sortiert. Strg+F zum schnellen Suchen.

@Autowired
Spring-Annotation für Dependency Injection. Empfohlen über dem Konstruktor (statt Feld). Spring sucht eine passende Bean und reicht sie rein.
@Bean
Annotation an einer Methode innerhalb einer @Configuration-Klasse — registriert deren Rückgabewert als Spring-Bean. Nutze, wenn du nicht selbst die Klasse annotieren kannst.
Bean
Java-Objekt, dessen Lebenszyklus (Instanziierung, Wiring, Zerstörung) von Spring verwaltet wird. Wird nie mit new erzeugt.
@BeforeEach / @BeforeAll
JUnit-Lifecycle: @BeforeEach läuft vor jeder Testmethode (z.B. fresh setup), @BeforeAll einmalig pro Klasse (muss static sein).
BindingResult
Spring-Objekt, das Validation-Fehler vom @Valid-DTO sammelt. Muss direkt nach dem zu validierenden Parameter stehen.
Bootstrap
CSS-Framework. 12-Spalten-Grid, vorgefertigte Komponenten (Cards, Modals, Carousel), Utility-Klassen für Spacing/Color/Display.
CascadeType
Steuert welche Operationen auf einem Parent (save/merge/remove) auf das Child weitergereicht werden. ALL kaskadiert alles — meist zu aggressiv.
@Configuration
Markiert eine Klasse als Konfigurations-Source („Configuration as Code"). Enthält typischerweise @Bean-Methoden.
Constructor Injection
DI per Konstruktor-Parameter. Vorteile: final-Felder möglich, im Test direkt aufrufbar, Pflicht-Abhängigkeiten explizit. Spring 3.5+ Best Practice.
Convention over Configuration
Spring-Boot-Prinzip: Best-Practice-Defaults statt jede Detail-Einstellung. Beispiel: Templates in resources/templates/ ohne extra Konfig.
Dependency Injection (DI)
Eine Klasse bekommt ihre Abhängigkeiten von außen übergeben statt sie selbst zu erzeugen. Reduziert Kopplung, erleichtert Tests.
Derived Query
Spring-Data-Mechanismus: Repository-Methodenname (z.B. findByTitleContaining) wird automatisch in eine Query übersetzt. Keine SQL/JPQL nötig.
DTO (Data Transfer Object)
Eigene Klasse für die API-Sicht, getrennt von der Entity. Verhindert Endlos-JSON, schützt sensible Felder, stabilisiert API.
@Entity / @Id / @GeneratedValue
JPA-Pflichtannotationen für persistierte Klasse: @Entity auf der Klasse, @Id auf dem PK-Feld, @GeneratedValue für Auto-Increment.
@EventListener(ApplicationReadyEvent.class)
Spring ruft die annotierte Methode genau einmal auf, sobald die App vollständig hochgefahren ist. Im Kurs in ManualTestBean.
Fake / Mock / Stub
Test-Doubles: Fake = manuelle Alternativ-Impl. Mock = auto-generiert, prüft Aufrufe. Stub = semi-auto, definiertes Antwortverhalten.
FetchType.LAZY / EAGER
JPA-Ladestrategie. LAZY lädt referenzierte Objekte erst bei Zugriff (braucht offene Transaktion). EAGER lädt sofort mit. Default je nach Beziehung.
Hibernate
Populärstes ORM-Framework, Default-Implementierung der JPA-Spec in Spring Boot. Übernimmt das tatsächliche Mapping Java ↔ DB.
@JoinColumn / @JoinTable
@JoinColumn definiert die FK-Spalte auf der owning side. @JoinTable die Verknüpfungstabelle bei Many-to-Many.
JPA (Jakarta Persistence API)
Java-Spec für ORM (früher JPA = Java Persistence API). Definiert Annotationen + EntityManager. Implementierung z.B. Hibernate.
JPQL
Object-Query-Sprache der JPA. Wie SQL, aber auf Klassen + Feldern statt Tabellen + Spalten. SELECT m FROM Movie m WHERE m.title = :t.
JsonPath
Pfad-Sprache für JSON-Assertions in Tests. $ = root, $[0] = erstes Array-Element, $.field = Feld, $.* = alle Kinder.
mappedBy
Markiert die inverse Seite einer bidirektionalen Beziehung. Wert = Feldname auf der owning side (mit @JoinColumn).
MapStruct
Compile-time Code-Generator für Mapper Entity ↔ DTO. Annotation: @Mapper(componentModel = "spring").
@MockBean
Spring-Test-Annotation: ersetzt eine Bean im Spring-Kontext durch einen Mockito-Mock. Default-Returns bis du mit when() stubbst.
MockMvc
Spring-Test-Werkzeug, das HTTP-Requests im Test simuliert ohne echten Server zu starten. Ersetzt manuelle Postman-Aufrufe.
ModelAndView
Thymeleaf-Controller-Rückgabe: kombiniert Template-Name + Model-Daten in einem Objekt. Alternative: String-Rückgabe + Model-Parameter.
OpenAPI / Swagger
Standard für maschinenlesbare REST-API-Beschreibung. Spring generiert sie automatisch aus deinen @RestController. UI unter /swagger-ui.html.
Persistence Context
Cache der „verwalteten" Entities innerhalb einer Transaktion. Änderungen werden beim Commit automatisch geschrieben.
PRG-Pattern
Post-Redirect-Get. Nach erfolgreichem POST per redirect: umleiten — verhindert Doppel-Submit beim Browser-Refresh.
@RequestBody / @RequestParam / @PathVariable
Quellen für Controller-Parameter: @RequestBody = JSON-Body. @RequestParam = Query-String. @PathVariable = Teil der URL.
@ResponseStatus
Setzt den HTTP-Status, der bei normalem Methodenrückgabe zurückgegeben wird. @ResponseStatus(HttpStatus.CREATED) für POST → 201.
@RestController
@Controller + @ResponseBody auf jeder Methode. Standard für JSON-APIs.
Schichtenmodell
Controller (HTTP-Schnittstelle) → Service (Business-Logik) → Repository (DB-Zugriff). Aufruf nur in dieser Richtung.
Spring Data JPA
Schicht über JPA, die Repository-Interfaces ohne Implementierung erlaubt. Nutze extends JpaRepository<T, ID>.
Stereotype
Spring-Begriff für die Schicht-Annotationen @Component, @Service, @Repository, @Controller. Funktional gleich, semantisch unterschiedlich.
th:object / th:field / th:errors
Thymeleaf Form-Trio: th:object bindet das Form-Objekt, th:field setzt id+name+value, th:errors rendert Validierungsfehler.
@Transactional
Spring-Annotation für deklarative Transaktionen. Pflicht für Lazy-Loading-Auflösung. Nur von außerhalb der Bean aufrufbar.
@Valid
Triggert Bean-Validation auf einem Methoden-Parameter. Constraints am DTO werden geprüft, Fehler landen in BindingResult (oder als 400).
@WebMvcTest
Lädt nur den MVC-Layer (Controller) für einen Test. Schneller als @SpringBootTest. Services brauchen @MockBean.
