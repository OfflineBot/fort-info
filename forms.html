7 · Forms

7.1 Formulare in Spring + Thymeleaf

Ein Formular hat in Spring drei Akteure:

  1. Eine Form-Klasse (DTO) mit den Feldern + Validierungs-Annotationen.
  2. Einen GET-Endpunkt, der das leere Form-Objekt ins Model legt und das Template rendert.
  3. Einen POST-Endpunkt, der das ausgefüllte Form mit @Valid entgegennimmt und entweder speichert (Redirect) oder bei Fehlern dasselbe Template erneut rendert.

7.2 th:object & th:field

Im Template aktiviert th:object die Selection-Expression *{…}, mit der du dann die Felder des Objekts referenzierst. th:field setzt automatisch id, name und value.

<form th:action="@{/awards}" th:object="${awardForm}" method="post">

  <div class="mb-3">
    <label class="form-label" for="academy">Academy</label>
    <input class="form-control" type="text" th:field="*{academy}">
  </div>

  <div class="mb-3">
    <label class="form-label" for="category">Kategorie</label>
    <input class="form-control" type="text" th:field="*{category}"
           th:classappend="${#fields.hasErrors('category')} ? 'is-invalid'">
    <div class="invalid-feedback" th:errors="*{category}"></div>
  </div>

  <div class="mb-3">
    <label class="form-label" for="celebrationYear">Jahr</label>
    <input class="form-control" type="number" th:field="*{celebrationYear}">
  </div>

  <button type="submit" class="btn btn-primary">Speichern</button>
</form>

7.3 Validation (@Valid)

Auf der Form-Klasse stehen Bean-Validation-Annotationen (Jakarta):

  • @NotNull — darf nicht null sein
  • @NotBlank — String, nicht null und nicht nur Whitespace
  • @NotEmpty — String/Collection, mind. ein Element
  • @Size(min=, max=) — Länge / Größe
  • @Min / @Max — Zahlenbereich
  • @Email — gültiges E-Mail-Format
  • @Pattern(regexp="…") — Regex
@Controller @RequestMapping("/awards")
public class AwardFormController {

    private final AwardService service;
    public AwardFormController(AwardService s) { this.service = s; }

    @GetMapping("/neu")
    public String form(Model model) {
        model.addAttribute("awardForm", new AwardDTO());
        return "awards/form";
    }

    @PostMapping
    public String save(@Valid @ModelAttribute("awardForm") AwardDTO form,
                       BindingResult br) {
        if (br.hasErrors()) return "awards/form";   // mit Fehlern zurück zum Formular
        service.addAward(form);
        return "redirect:/awards";                   // PRG-Pattern
    }
}

PRG-Pattern (Post-Redirect-Get): nach erfolgreichem POST redirect auf eine GET-Seite, damit ein Browser-Refresh nicht den POST wiederholt.

@NotNull vs @NotBlank vs @NotEmpty — Unterschied?

Antwort anzeigen
@NotNull: Wert darf nicht null sein (leerer String wäre ok). @NotEmpty: für Strings/Collections — nicht null und nicht leer (whitespace ok). @NotBlank: nur Strings — nicht null, nicht leer, nicht nur Whitespace.

Was passiert, wenn ein Formular die @Valid-Constraints nicht erfüllt?

Antwort anzeigen
Die Validierung schlägt fehl, der Service wird nicht aufgerufen. BindingResult wird mit den Fehlern befüllt. Best Practice: dasselbe Form-Template wieder rendern, damit der User korrigieren kann.

Wo MUSS BindingResult in der Parameterliste stehen?

Antwort anzeigen
Direkt nach dem mit @Valid annotierten Objekt. Sonst sieht Spring die Bindung als unvollständig und wirft eine Exception.

Erkläre das PRG-Pattern.

Antwort anzeigen
Post-Redirect-Get: nach erfolgreichem POST gibst du redirect:/path zurück, damit der Browser per GET die nächste Seite holt. Vorteil: ein Refresh wiederholt nicht den POST und verhindert Doppel-Submit.

Wie zeigst du im Template einen Validierungsfehler für das Feld category an?

Antwort anzeigen
<p th:if="${#fields.hasErrors('category')}" th:errors="*{category}"></p>. Mit Bootstrap zusätzlich th:classappend="${#fields.hasErrors('category')} ? 'is-invalid'" auf dem Input.

Welche Spring-Annotation bindet das POST-Body-Form an dein DTO?

Antwort anzeigen
@ModelAttribute("name") FormDTO form — Spring liest die Form-Felder und mappt sie auf die DTO-Properties. Mit @Valid davor wird Bean Validation ausgeführt.
