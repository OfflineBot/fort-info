Frage 1 Spring
Welche Stereotype-Annotation gehört zu welcher Schicht? Ordne zu:
(a) HTTP-API mit JSON · (b) Geschäftslogik · (c) Datenzugriff · (d) generische Bean
→ @RestController, @Service, @Repository, @Component
Antwort + Erklärung
(a) @RestController · (b) @Service · (c) @Repository · (d) @Component. Alle drei spezifischen sind @Component-Subtypen mit semantischer Bedeutung.
Frage 2 Spring
Was ist an diesem Code falsch und wie korrigierst du ihn?
@Controller
public class MovieControllerImpl {
    private MovieService service = new MovieServiceImpl();
}
Antwort + Erklärung
Direktes new umgeht Spring komplett — die Bean kommt nicht aus dem Container, eingebettete Abhängigkeiten sind null. Korrektur per Konstruktor-Injection:
@Controller
public class MovieControllerImpl {
    private final MovieService service;
    public MovieControllerImpl(MovieService service) { this.service = service; }
}
Frage 3 Spring
Nenne die drei Injection-Typen und welche der Kurs als Best-Practice empfiehlt.
Antwort + Erklärung
Constructor Injection (über Konstruktor) · Setter Injection (Setter mit @Autowired) · Field Injection (Feld mit @Autowired). Empfohlen: Constructor Injection — final-Felder, test-freundlich, explizite Pflicht-Abhängigkeiten.
Frage 4 Spring
Was sind die vier Kernprinzipien von Spring laut Folie?
Antwort + Erklärung
1) Convention over Configuration · 2) Modularisierung · 3) Schichtenorientierung · 4) Dependency Injection.
Frage 5 JPA
Was bedeutet mappedBy und was passiert ohne diesen Parameter bei einer bidirektionalen Beziehung?
Antwort + Erklärung
mappedBy kennzeichnet die inverse Seite — die owning Seite (mit @JoinColumn) verwaltet die FK-Spalte. Ohne mappedBy hält JPA beide Seiten für owning und legt zwei Join-Tabellen an statt einer.
Frage 6 JPA
Schreibe eine Derived Query, die alle Filme nach dem Premiere-Datum X mit IMDB-Rating > Y sortiert nach Premiere absteigend findet.
Antwort + Erklärung 
List<Movie> findByPremiereDateAfterAndImdbRatingGreaterThanOrderByPremiereDateDesc(
    LocalDate stichdatum, double minRating);
Frage 7 JPA
Wozu dient @Transactional? Welche Regel zur Verwendung kennst du laut Folie?
Antwort + Erklärung
Bündelt mehrere DB-Operationen in eine Transaktion. Lazy-Beziehungen können nur innerhalb des Transaktionskontexts aufgelöst werden. Regel: Transaktionen können nur von außerhalb einer Bean gestartet werden.
Frage 8 JPA
Schreibe die JPA-Entity Movie mit Feldern id, title, imdbRating, und Beziehung zum Director (n:1).
Antwort + Erklärung 
@Getter @Setter @NoArgsConstructor
@Entity
public class Movie {
    @Id @GeneratedValue
    private Long id;
    private String title;
    private double imdbRating;

    @ManyToOne(cascade = CascadeType.ALL)
    @JoinColumn(name = "director_id")
    private Director director;
}
Frage 9 JPA
Welche Annotation in welcher Beziehung? Movie ↔ Soundtrack (1:1, ein Film hat genau einen Soundtrack).
Antwort + Erklärung
Auf der owning Seite (z.B. Soundtrack): @OneToOne + @JoinColumn(name="movie_id"). Auf der inversen Seite (Movie): @OneToOne(mappedBy = "movie").

@ResponseStatus(HttpStatus.CREATED)

Frage 11 REST
Erkläre Unterschied zwischen @PathVariable und @RequestParam mit URL-Beispielen.
Antwort + Erklärung
@PathVariable: Teil der URL (/awards/5) → Ressource identifizieren. @RequestParam: Query-String (/awards?year=2020) → Filter, Sortierung, Pagination.
Frage 12 REST
Warum trennt man DTO von Entity? Nenne drei Gründe.
Antwort + Erklärung
1) API-Stabilität: Entity-Refactor bricht den Contract nicht. 2) Sicherheit: sensitive Felder werden nicht serialisiert. 3) Endlos-Loops vermeiden bei bidirektionalen Beziehungen.
Frage 13 REST
Welche HTTP-Methode ist idempotent? Was bedeutet idempotent?
Antwort + Erklärung
Idempotent = mehrfache Ausführung erzeugt dasselbe Ergebnis wie eine einmalige Ausführung. GET, PUT, DELETE sind idempotent. POST & PATCH nicht (jedes POST legt potentiell neue Ressource an).
Frage 14 REST
MapStruct: was macht componentModel = "spring" und @InheritInverseConfiguration?
Antwort + Erklärung
componentModel = "spring": generierter Mapper wird als Spring-Bean (@Component) registriert — kann injiziert werden. @InheritInverseConfiguration: spiegelt die Mapping-Regeln des Forward-Mappings automatisch — kein doppeltes Schreiben.
Frage 15 Testing
Was bedeutet dieser JsonPath: $[1].awards[0].celebrationYear?
Antwort + Erklärung
„Jahr des ersten Awards des zweiten Films" — bei Liste-Response: zweites Listenelement (Index 1), dessen Feld awards ist ein Array, davon das erste Element (Index 0), dessen Feld celebrationYear.
Frage 16 Testing
Was startet @WebMvcTest(controllers = MovieControllerImpl.class)? Was wird nicht geladen?
Antwort + Erklärung
Gestartet: nur der MVC-Layer (Controller, ControllerAdvice, Filters, JSON-Konverter). Nicht geladen: Services (per @MockBean mocken), Repositories, DB, normale @Component-Beans.
Frage 17 Testing
Schreibe einen Test: GET auf /api/v1/movies/99 erwartet 404, wenn Service NoSuchElementException wirft.
Antwort + Erklärung 
@Test
public void shouldFailGetMovie() throws Exception {
    when(movieService.getMovieById(anyLong()))
        .thenThrow(new NoSuchElementException("not found"));

    mockMvc.perform(get("/api/v1/movies/99"))
           .andExpect(status().isNotFound());

    verify(movieService).getMovieById(99L);

Frage 18 Testing
Warum fehlt das when() in einem Constraint-Violation-Test, und was prüfst du stattdessen?
Antwort + Erklärung
Bei @Valid-Verletzung wirft Spring die Exception vor dem Controller — der Service-Call findet nicht statt, also nichts zu stubben. Pflicht: verify(service, never()).addMovie(any()).
Frage 19 Testing
Wie prüfst du in MockMvc, dass eine JSON-Liste exakt 3 Elemente hat und das zweite Element title=„Inception"?
Antwort + Erklärung 
.andExpect(jsonPath("$.*", hasSize(3)))
.andExpect(jsonPath("$[1].title", is("Inception")))
Frage 20 Testing
Erkläre Stub vs. Mock am Banking-Beispiel der Folie.
Antwort + Erklärung
Stub bildet Antwortverhalten nach (Konto 100€ → Transaktion → 80€), prüft den Endzustand. Mock prüft nur, dass der Transaktionsbefehl korrekt an den Bankserver gesendet wurde — der Kontostand ist egal.

Frage 23 Webdesign
Was bewirkt jeweils g-3, mt-4, img-fluid?
Antwort + Erklärung
g-3: Gap (Abstand) zwischen Spalten in einer row. mt-4: Margin-Top Stufe 4. img-fluid: Bild responsive (max-width: 100%, height: auto).
Frage 24 Thymeleaf
Was bedeuten die vier Expression-Typen ${…}, *{…}, @{…}, ~{…}?
Antwort + Erklärung
${var} Variable im Model · *{feld} Selection innerhalb th:object · @{/url} URL mit Context-Path · ~{frag :: id} Fragment-Referenz.
Frage 25 Thymeleaf
Unterschied zwischen th:insert und th:replace?
Antwort + Erklärung
th:insert packt das Fragment in den umschließenden Tag (Tag bleibt). th:replace ersetzt den Tag komplett durch das Fragment.

Frage 27 Thymeleaf
Was leistet der Ternary-Operator in Thymeleaf? Beispiel.
Antwort + Erklärung
Kurzschreibweise für If-Then-Else innerhalb einer Expression. th:text="${(age > 18) ? 'adult' : 'student'}". Praktisch in th:classappend: ${stat.even ? 'gerade' : 'ungerade'}.
Frage 28 Forms
Erkläre @NotNull vs @NotBlank vs @NotEmpty jeweils mit dem Effekt bei einem String " " (3 Leerzeichen).
Antwort + Erklärung
@NotNull: erlaubt (nicht null). @NotEmpty: erlaubt (nicht leer — Whitespace zählt als Inhalt). @NotBlank: verbietet (nach trim leer). Faustregel für Texteingaben: @NotBlank.
Frage 29 Forms
Was ist das PRG-Pattern und warum nutzt man es?
Antwort + Erklärung
Post-Redirect-Get: nach erfolgreichem POST gibt der Controller "redirect:/path" zurück. Browser holt die nächste Seite per GET. Verhindert Doppel-Submit beim Refresh.
Frage 30 Forms
Schreibe einen Controller-Endpoint zum Speichern eines AwardForms mit Validierung.
Antwort + Erklärung 
@PostMapping
public String save(@Valid @ModelAttribute("awardForm") AwardDTO form,
                   BindingResult br) {
    if (br.hasErrors()) return "awards/form";
    awardService.addAward(form);
    return "redirect:/awards";
}
BindingResult MUSS direkt nach dem @Valid-Objekt stehen.
