15 Fragen

Frage 1 Spring
Welche Stereotype-Annotation gehört zu welcher Schicht? Ordne zu:
(a) HTTP-API mit JSON · (b) Geschäftslogik · (c) Datenzugriff · (d) generische Bean
→ @RestController, @Service, @Repository, @Component
Antwort + Erklärung
(a) @RestController · (b) @Service · (c) @Repository · (d) @Component. Alle drei spezifischen sind @Component-Subtypen mit semantischer Bedeutung.
Frage 2 Spring
Was ist an diesem Code falsch und wie korrigierst du ihn?
@Controller
public class MovieControllerImpl {
    private MovieService service = new MovieServiceImpl();
}
Antwort + Erklärung
Direktes new umgeht Spring komplett — die Bean kommt nicht aus dem Container, eingebettete Abhängigkeiten sind null, Tests müssen die Klasse umgehen. Korrektur per Konstruktor-Injection:
@Controller
public class MovieControllerImpl {
    private final MovieService service;
    public MovieControllerImpl(MovieService service) { this.service = service; }
}
Frage 3 JPA
Was bedeutet mappedBy und was passiert ohne diesen Parameter bei einer bidirektionalen Beziehung?
Antwort + Erklärung
mappedBy kennzeichnet die inverse Seite einer Beziehung — die owning Seite (mit @JoinColumn) verwaltet die Fremdschlüsselspalte. Ohne mappedBy hält JPA beide Seiten für owning und legt zwei Join-Tabellen an statt einer.
Frage 4 JPA
Schreibe eine Derived Query, die alle Filme nach dem Premiere-Datum X mit IMDB-Rating > Y sortiert nach Premiere absteigend findet.
Antwort + Erklärung 
List<Movie> findByPremiereDateAfterAndImdbRatingGreaterThanOrderByPremiereDateDesc(
    LocalDate stichdatum, double minRating);
Lange Methodennamen sind OK — alternativ schreibst du eine @Query.
Frage 5 JPA
Wozu dient @Transactional und welche Regel zur Verwendung kennst du laut Folie?
Antwort + Erklärung
@Transactional bündelt mehrere DB-Operationen in eine Transaktion. Lazy-Loaded Beziehungen können nur innerhalb des Transaktionskontexts aufgelöst werden. Regel: Transaktionen können nur von außerhalb einer Bean gestartet werden — interner Methodenaufruf in derselben Bean ignoriert die Annotation.
Frage 6 REST
Vervollständige den Award-Endpoint: POST /api/v1/awards, gibt Status 201, validiert den Body.
Antwort + Erklärung 
@PostMapping
@ResponseStatus(HttpStatus.CREATED)
public AwardDTO addAward(@Valid @RequestBody AwardDTO award) {
    return awardService.addAward(award);
}
Frage 7 REST
Erkläre den Unterschied zwischen @PathVariable und @RequestParam mit URL-Beispielen.
Antwort + Erklärung
@PathVariable kommt aus der URL selbst: GET /awards/5 → @PathVariable Long id. @RequestParam kommt aus dem Query-String: GET /awards?year=2020 → @RequestParam Integer year. PathVariable identifiziert eine Ressource, RequestParam filtert/sortiert/paginiert.
Frage 8 REST
Warum trennt man DTO von Entity? Nenne drei konkrete Gründe.
Antwort + Erklärung
1) API-Stabilität: Refactor der Entity bricht den Contract nicht. 2) Sicherheit: sensitive Felder (Passwort-Hash, interne IDs) werden nicht serialisiert. 3) Endlos-Loops vermeiden: bei bidirektionalen Beziehungen würde Jackson sonst zirkulär serialisieren.
Frage 9 Testing
Was bedeutet dieser JsonPath: $[1].awards[0].celebrationYear?
Antwort + Erklärung
„Jahr des ersten Awards des zweiten Films" — bei einer Liste-Response: zweites Listenelement (Index 1), dessen Feld awards ist ein Array, davon das erste Element (Index 0), dessen Feld celebrationYear.
Frage 10 Testing
Was startet @WebMvcTest(controllers = MovieControllerImpl.class)? Was wird nicht geladen?
Antwort + Erklärung
Gestartet: nur der MVC-Layer (Controller + ControllerAdvice + Filters + JSON-Konverter) für die angegebene Klasse. Nicht geladen: Services (musst per @MockBean mocken), Repositories, DB, normale @Component-Beans. → schnelle Tests ohne DB-Setup.
Frage 11 Testing
Schreibe einen Test, der einen GET auf /api/v1/movies/99 macht und 404 erwartet, wenn der Service NoSuchElementException wirft.
Antwort + Erklärung 
@Test
public void shouldFailGetMovie() throws Exception {
    when(movieService.getMovieById(anyLong()))
        .thenThrow(new NoSuchElementException("not found"));

    mockMvc.perform(get("/api/v1/movies/99"))
           .andExpect(status().isNotFound());

    verify(movieService).getMovieById(99L);
}
Frage 12 Testing
Warum fehlt das when() in einem Constraint-Violation-Test, und was musst du stattdessen prüfen?
Antwort + Erklärung
Bei einer @Valid-Verletzung wirft Spring die Exception vor dem Controller — der Service-Call findet gar nicht erst statt. Also gibt es nichts zu stubben. Pflicht-Assertion: verify(service, never()).addMovie(any()) — beweist, dass der Validator den Request abgefangen hat.
Frage 13 Webdesign
Wie definierst du in Bootstrap 5 ein Layout mit 3 gleich breiten Spalten ab Tablet, gestapelt mobil?
Antwort + Erklärung 
<div class="container">
  <div class="row g-3">
    <div class="col-12 col-md-4">…</div>
    <div class="col-12 col-md-4">…</div>
    <div class="col-12 col-md-4">…</div>
  </div>
</div>
col-12 = volle Breite (Mobile), col-md-4 = 4/12 ab md-Breakpoint (≥ 768 px).
Frage 14 Thymeleaf
Was bedeuten die vier Expression-Typen ${…}, *{…}, @{…}, ~{…}?
Antwort + Erklärung
${var} Variable im Model (OGNL) · *{feld} Selection innerhalb th:object · @{/url} URL mit Context-Path · ~{frag :: id} Fragment-Referenz für th:insert/th:replace.
Frage 15 Forms
Erkläre @NotNull vs @NotBlank vs @NotEmpty jeweils mit dem konkreten Effekt bei einem String " " (3 Leerzeichen).
Antwort + Erklärung
@NotNull: erlaubt (String ist nicht null). @NotEmpty: erlaubt (String ist nicht leer — Whitespace zählt als Inhalt). @NotBlank: verbietet (String ist nach trim leer). Faustregel für Texteingaben: immer @NotBlank.
