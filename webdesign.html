📄 Folien-PDF anzeigen / herunterladen 5-Webdesign.pdf

🎯 TL;DR — was du wirklich wissen musst

  • HTML ist die Strukturschicht. Semantische Tags (header/main/article) statt nur div.
  • CSS 3 Wege: inline (schlecht) · <style> im Head · externe Datei via <link> (Standard).
  • Bootstrap-Grid: container > row > col-{N|md-N|lg-N}. 12 Spalten, mobile-first.
  • Breakpoints: sm ≥576 · md ≥768 · lg ≥992 · xl ≥1200 · xxl ≥1400 px.
  • Bootstrap CSS-Klassen für Spacing (mt-3, g-3), Tabellen (table-striped), Bilder (img-fluid).
  • Carousel: .carousel.slide + data-bs-ride="carousel" + Prev/Next-Buttons mit data-bs-target.

5.1 HTML-Grundlagen

HTML ist die Strukturschicht. Die wichtigsten Tags für die Übungen:

  • <h1>…<h6> — Überschriften
  • <p> — Absatz
  • <img src="…"> — Bild (selbstschließend)
  • <a href="…"> — Link
  • <table>, <thead>, <tbody>, <tr>, <th>, <td> — Tabellen
  • <ul> / <ol> + <li> — Listen
  • <div> / <span> — Container
  • <strong> / <br> — fett / Zeilenumbruch
<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
</head>
<body>
    <h1>Interstellar (2014)</h1>
    <img src="cover.jpg">
    <h2>Summary</h2>
    <p>A team of explorers travel through a wormhole in space …</p>
    <strong>Director: </strong>Christopher Nolan
</body>
</html>

5.2 CSS

CSS ist die Präsentationsschicht. Drei Möglichkeiten zur Einbindung:

  1. Inline: style="color:red" — schlechteste Variante.
  2. Im <head>: <style>…</style>.
  3. Externe Datei: <link rel="stylesheet" href="css/style.css"> — Standard.
.top {
  text-align: center;
  margin-bottom: 1.5rem;
}

table {
  border-collapse: collapse;
  width: 100%;
}
th, td {
  padding: .5rem;
  border: 1px solid #ccc;
}

Wichtige Selektoren

  • elem — alle Elemente dieses Tags
  • .klasse — alle mit class="klasse"
  • #id — das Element mit id="id"
  • elem.klasse — kombiniert
  • parent > child — direkter Nachfahre
  • a:hover — Pseudo-Klasse

5.3 Bootstrap 5

Bootstrap ist ein CSS-Framework mit fertigen Komponenten und einem 12-Spalten-Grid. Im Kurs wird über CDN eingebunden:

<link rel="stylesheet"
      href="https://cdn.jsdelivr.net/npm/bootstrap@5.0.1/dist/css/bootstrap.min.css">

<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.0.1/dist/js/bootstrap.bundle.min.js"></script>

Grid-System

<div class="container">
  <div class="row g-0">
    <div class="col-4">Cover-Bild</div>
    <div class="col-8">Trailer-Bild</div>
  </div>
</div>

Im Kurs verwendete Klassen

KlasseWirkung
containerzentrierter, responsive Wrapper
row / col-N12-Spalten-Grid
g-0 bis g-5Gap zwischen Spalten
mt-4, mb-4Margin top/bottom Stufe 4
img-fluid / w-100Bild responsive / volle Breite
table table-striped table-hovergestyltes Tabellen-Set
carouselBildkarussell

Carousel-Komponente (aus Aufgabe 9)

<div id="carouselExampleControls" class="carousel slide" data-bs-ride="carousel">
  <div class="carousel-inner">
    <div class="carousel-item active">
      <img src="bild1.jpg" class="d-block w-100" alt="...">
    </div>
    <div class="carousel-item">
      <img src="bild2.jpg" class="d-block w-100" alt="...">
    </div>
  </div>
  <button class="carousel-control-prev" type="button"
          data-bs-target="#carouselExampleControls" data-bs-slide="prev">
    <span class="carousel-control-prev-icon" aria-hidden="true"></span>
    <span class="visually-hidden">Previous</span>
  </button>
  <button class="carousel-control-next" type="button"
          data-bs-target="#carouselExampleControls" data-bs-slide="next">
    <span class="carousel-control-next-icon" aria-hidden="true"></span>
    <span class="visually-hidden">Next</span>
  </button>
</div>

⚙ Aufgabe 7 — Pure HTML

Aufgabenstellung
📦 Starter-ZIP ✅ Lösungs-ZIP

Lege eine Datei movie-profile.html an, die das Profil eines Films (Interstellar) darstellt — ohne CSS, nur mit semantischem HTML:

  • Titel + Erscheinungsjahr als h1
  • Cover-Bild (von IMDB-URL)
  • Summary als p
  • Director / Writers / Stars als fette Labels
  • Cast-Tabelle (Artist name / Role name) mit thead + tbody
<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
</head>
<body>
    <h1>Interstellar (2014)</h1>
    <img src="https://m.media-amazon.com/images/M/MV5B…UX182_AL_.jpg">

    <h2>Summary</h2>
    <p>A team of explorers travel through a wormhole in space in an attempt
       to ensure humanity's survival.</p>
    <strong>Director: </strong>Christopher Nolan<br>
    <strong>Writers: </strong>Jonathan Nolan, Christopher Nolan<br>
    <strong>Stars: </strong>Matthew McConaughey, Anne Hathaway, Jessica Chastain

    <h2>Cast:</h2>
    <table>
        <thead>
            <tr><th>Artist name</th><th>Role name</th></tr>
        </thead>
        <tbody>
            <tr><td>Ellen Burstyn</td><td>Murph (Older)</td></tr>
            <tr><td>Matthew McConaughey</td><td>Cooper</td></tr>
            <tr><td>Mackenzie Foy</td><td>Murph (10 Yrs.)</td></tr>
            <tr><td>John Lithgow</td><td>Donald</td></tr>
        </tbody>
    </table>
</body>
</html>

⚙ Aufgabe 8 — eigenes CSS

Aufgabenstellung
📦 Starter-ZIP

Erweitere das Profil aus Aufgabe 7 um eigenes CSS in einer separaten Datei css/style.css. Pack Cover- und Trailer-Bild nebeneinander in einen Container .top. Style die Tabelle.

movie-profile.html bekommt im <head>:

<link rel="stylesheet" href="css/style.css">

Layout-Skelett mit Container:

<div class="top">
    <h1>Interstellar (2014)</h1>
    <table>
        <tr>
            <td><img src="cover.jpg"></td>
            <td>
                <a href="https://www.youtube.com/watch?v=k-iI-vftGGE">
                    <img src="trailer.jpg">
                </a>
            </td>
        </tr>
    </table>
</div>

Beispiel-CSS:

body { font-family: sans-serif; max-width: 960px; margin: 2rem auto; }
.top { text-align: center; margin-bottom: 1.5rem; }
.top img { max-width: 300px; height: auto; }

table { border-collapse: collapse; width: 100%; margin-top: 1rem; }
th, td { padding: .5rem .8rem; border: 1px solid #ccc; }
thead th { background: #f3f3f3; }

⚙ Aufgabe 9 — Bootstrap + Carousel

Aufgabenstellung
📦 Starter-ZIP

Baue das Movie-Profile mit Bootstrap 5 neu auf. Anforderungen:

  • Bootstrap CDN einbinden (CSS & JS)
  • Cover- + Trailer-Bild via .row .col-4 / .col-8 nebeneinander
  • Cast-Tabelle mit .table .table-striped .table-hover
  • Awards als ungeordnete Liste
  • Soundtrack als geordnete Liste
  • Bilderkarussell (carousel) am Ende mit mehreren Szenenbildern

Komplette Lösung im Lösungs-ZIP. Schlüsselausschnitte:

<div class="container">
  <div class="top">
    <h1>Interstellar (2014)</h1>
    <div class="row g-0">
      <div class="col-4">
        <img class="img-fluid w-100" src="cover.jpg">
      </div>
      <div class="col-8">
        <img class="img-fluid w-100" src="trailer.jpg">
      </div>
    </div>
  </div>

  <h2 class="mt-4">Cast:</h2>
  <table class="table table-striped table-hover"> … </table>

  <h2 class="mt-4 mb-4">Pictures</h2>
  <div id="carouselExampleControls" class="carousel slide" data-bs-ride="carousel">
    … (siehe Codebeispiel unter §5.3)
  </div>
</div>

Lerneffekt: dieselbe Seite drei Mal — pure HTML (Aufgabe 7) → eigenes CSS (Aufgabe 8) → Bootstrap (Aufgabe 9). Du siehst direkt, wie viel weniger CSS du selbst schreiben musst, sobald du ein Framework nutzt, und welchen Trade-off du dafür eingehst (HTML wird "klassen-lastig").

⚙ Weitere Aufgabe 1 — Director-Profilseite

Aufgabenstellung

Baue analog zum Movie-Profile (Aufgabe 9) eine director-profile.html mit Bootstrap:

  1. Header mit Director-Name + Geburtsjahr (h1)
  2. 2-Spalten-Layout: links Profilbild (col-3), rechts Bio-Text (col-9)
  3. Filmografie als Bootstrap-Card-Grid (3 Spalten ab md, 1 Spalte mobil)
  4. Awards-Übersicht als Badge-Liste (z.B. span.badge bg-warning)
<div class="container py-4">
  <h1>Christopher Nolan <small class="text-muted">(*1970)</small></h1>

  <div class="row mt-4">
    <div class="col-3">
      <img src="nolan.jpg" class="img-fluid rounded">
    </div>
    <div class="col-9">
      <p>Britisch-amerikanischer Filmregisseur, bekannt für komplexe Erzählstrukturen.</p>
      <span class="badge bg-warning text-dark">Oscar 2024</span>
      <span class="badge bg-warning text-dark">BAFTA 2024</span>
    </div>
  </div>

  <h2 class="mt-5">Filmografie</h2>
  <div class="row g-3 mt-2">
    <div class="col-12 col-md-4">
      <div class="card h-100">
        <img src="interstellar.jpg" class="card-img-top">
        <div class="card-body">
          <h5 class="card-title">Interstellar (2014)</h5>
          <p class="card-text">Sci-Fi-Epos.</p>
        </div>
      </div>

Tipp: h-100 auf den Cards sorgt dafür, dass alle in einer Zeile gleich hoch sind, auch wenn der Text unterschiedlich lang ist.

🧠 Verständnis-Checks

Klick auf „Antwort anzeigen" — schnelles Selbstabfragen ohne Scrollen.

Welche drei Möglichkeiten gibt es, CSS einzubinden — und welche ist Standard?

Antwort anzeigen
Inline-Style, <style> im Head, oder <link rel="stylesheet" href="…"> auf eine externe Datei. Letzteres ist Standard (Wiederverwendung, Caching, Trennung von HTML & CSS).

Was bedeutet col-md-4 in Bootstrap?

Antwort anzeigen
Ab dem Breakpoint md (≥ 768 px) nimmt das Element 4 von 12 Grid-Spalten ein. Drunter (Mobile) füllt es per Default die volle Breite (eine Spalte pro Zeile).

Wie definierst du in Bootstrap drei gleich breite Spalten nebeneinander?

Antwort anzeigen
<div class="row"> mit drei <div class="col-4"> oder col-md-4 für Mobile-First-Verhalten.

Welche Bootstrap-Klassen regeln Abstand und Margin?

Antwort anzeigen
g-0 bis g-5 auf der row regelt den Gap zwischen Spalten. Für Margin: mt-X, mb-X, my-X.

Welche didaktische Progression haben Aufgabe 7, 8 und 9?

Antwort anzeigen
Dieselbe Movie-Profile-Seite drei Mal: 7 = pure HTML, 8 = HTML + eigenes CSS, 9 = HTML + Bootstrap (inkl. Carousel). Du siehst direkt den Trade-off: weniger eigenes CSS, dafür klassen-lastiges HTML.

Welches Bootstrap-JavaScript-Plugin nutzt Aufgabe 9?

Antwort anzeigen
Das carousel-Plugin für ein Bilderkarussell — eingebunden via <script src="bootstrap.bundle.min.js"> + data-bs-ride="carousel" + Prev/Next-Buttons mit data-bs-slide.
